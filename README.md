# StudySpot 🪑

#### StudySpot is an Android app that helps students find and reserve available study seats in campus libraries.

### Features
- 🪑 Real-time seat availability
- 📍 Library & seat selection
- 📅 Seat reservations
- ⏱️ Reservation tracking
- 🔔 Booking notifications
- 🤖 AI-powered study recommendations

### Tech Stack
- Kotlin
- Jetpack Compose
- FastAPI
- PostgreSQL
- Python
- AI/ML

### Architecture

Android App → FastAPI Backend → PostgreSQL + AI Service

> Built as part of the CSE226 Android Project.
